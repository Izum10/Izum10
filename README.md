About

I finished my Honours Specialization in Computer Science at Western. My undergraduate thesis built an automated pipeline for scoping reviews, and before that I spent 16 months at Celestica as an RPA developer working on enterprise automation across SAP and Blue Prism.

The thread through most of my work is automating processes that people assume have to stay manual, then checking whether the automated version actually holds up against the manual baseline.

Currently working with Python, Java, React, and Node.js, and moving further into applied AI.


Research and Projects

Undergraduate Thesis: Automated Scoping Review Pipeline

<sub>Supervised by Dr. Pavlos Bobos, Western University</sub>

Scoping reviews in health research involve a lot of manual searching, screening, and data extraction. I built a modular pipeline in Python using NLP techniques and the PubMed API to handle those stages as one integrated workflow rather than a set of disconnected tools, then evaluated it on a live physiotherapy review question against a manual baseline.
