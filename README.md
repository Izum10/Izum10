### Undergraduate Thesis: Automated Scoping Review Pipeline
**Western University** · *Supervised by Dr. Pavlos Bobos*

Scoping reviews in health research involve a lot of manual searching, screening, and data extraction. I built an end-to-end pipeline in **Python** (PubMed API, Pandas, scikit-learn, spaCy) to handle those stages as one integrated workflow rather than a set of disconnected tools. Screening uses an **SVM + TF-IDF classifier**, and extraction uses **rule-based NER**. I evaluated it on a live physiotherapy review question against a two-reviewer manual baseline.
